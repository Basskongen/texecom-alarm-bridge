# Texecom apps for Home Assistant

Add this repository in Home Assistant under Settings > Apps > App store > three dots >
Repositories:

```
https://github.com/Basskongen/texecom-hassio
```

Then install **Texecom Alarm Bridge** and read its Documentation tab.

This is an independent project. It is not made, endorsed or supported by Texecom.

say which alarm panels the app works with.
